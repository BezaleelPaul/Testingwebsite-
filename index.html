Orbital Observatory: 3D Keplerian Engine

Interactive solar-system model with Keplerian orbital mechanics, procedural worlds, and optional NASA Open API context.

Three.jsReact Three FiberNASA Open APIKeplerian PhysicsGLSL ShadersNext.jsTypeScript
SourceLive project
Read the case notesClose case notes

The problem

Accurate astronomical modeling requires implementing Keplerian orbital equations and eccentric-anomaly corrections while keeping WebGL rendering responsive.

The approach

Built a React Three Fiber celestial canvas around a custom Keplerian solver, with a lightweight background mode and a separate observational view for NASA APOD and near-Earth object data.

What shipped

  • Custom Keplerian orbital solver computing true anomaly via Newton-Raphson approximation
  • NASA Open API context for daily astronomy imagery and near-Earth asteroid data
  • Multi-camera orbital rig with free-flight, chase, cockpit, and planetary orbit modes

The problem

Real-time cardiovascular stress modeling often lacks proactive recovery forecasting, relying instead on static retrospective metrics.

The approach

Engineered a predictive digital twin combining machine learning algorithms with interactive telemetry to forecast heart rate response windows and recovery dynamics.

What shipped

  • Dynamic cardiac load response simulation based on user strain inputs
  • XGBoost-powered recovery window forecasting algorithms
  • Multi-metric telemetry dashboards with real-time visual variance tracking

The approach
